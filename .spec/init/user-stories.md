# Histórias de Usuário Canônicas
## US-01: Navegação por Sidebar Mobile-First
- Dado que estou autenticado, quando visualizo qualquer página do sistema, então devo ver a barra lateral com os links corretos (Dashboard, Treinos, Perfil) e tema Dark com roxo #8B5CF6.
## US-02: Escaneamento de Ficha de Papel por IA
- Dado uma foto com o item "Pulldown Frente 3x12", quando o backend processa a imagem com a IA, então ele deve associar ao exercício "Puxada Frontal" já existente no banco de dados e criar o treino sem duplicatas.
## US-03: Recomendação de Sobrecarga Progressiva
- Dado que no último treino fiz Supino 3x12 com 30kg, quando abro o Treino A para executar hoje, então a IA deve sugerir: "Subir para 32kg para 8-10 reps".
## US-04: Monitoramento de Assimetrias e Frequência
- Dado que nas últimas 7 dias realizei 16 séries de Peito e 0 de Quadríceps, quando acesso a Dashboard, então devo ver o alerta em destaque indicando a negligência de membros inferiores.
